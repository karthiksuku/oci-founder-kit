# GitHub landing-page visuals

Created 13 November 2026 for OCI Founder Kit. Assets are distributed with the
repository's UPL-1.0 license; no official Oracle logo or proprietary icon set is bundled.

- `hero.svg` and `hero-mobile.svg`: original vector artwork for the repository.
- `workflow.png` and `workflow-mobile.png`: permanent PNG exports from an
  editable Figma/FigJam workflow, with desktop and mobile layouts. Its source
  uses native shapes, connectors and text and is retained by the maintainer.
- `getting-started.mmd`: the Mermaid source used to generate the initial FigJam
  diagram. Layout and typography were subsequently refined in FigJam.

The README uses responsive picture sources for smaller screens. Visitors can
view the committed images without Figma access. Private workspace links,
file identifiers, temporary export URLs and claim tokens are not published.
To adapt the workflow, reuse the Mermaid source in your own diagram workspace.
