# Fictional Vercel migration discovery fixture

This source fragment demonstrates discovery. It is not an installable application,
an OCI deployment or a successful migration receipt. It contains no real data,
credentials or provider identifiers.

From the kit root:

```sh
python3 skills/oci-migrate-web/scripts/web_scan.py examples/migrate-vercel
```

Expected review topics: Next.js runtime, Vercel object storage, middleware,
server handlers, routing, schedules and environment variable names. The scanner
does not execute the code or install its illustrative dependencies. Use
`oci-migrate-web` on the actual application to perform and verify adaptation.
