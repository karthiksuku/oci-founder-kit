Installation guide
Prefer the terminal?+

Requires Git, Python 3.11+ and your installed coding agent. Create your app folder first, then run these commands from outside it. Replace the example path with your app’s absolute path.

git clone https://github.com/karthiksuku/oci-founder-kit.git
python3 oci-founder-kit/scripts/install.py \
  --project /absolute/path/to/my-app --agent codex
cd /absolute/path/to/my-app

Then start your agent in the app folder and use $oci-kit. Claude plugin option →
