# Questions investors ask about cloud and AI cost

Answer each from the model and the founder's facts. If the answer is not
known, say what would establish it and when.

| Question | Where the answer comes from |
|---|---|
| What is gross margin at list price, without credits? | Durable gross margin, current and horizon months |
| How much of the current margin is credits? | Cash margin minus durable margin, month 1 |
| What happens when the credits end? | Credit cliff month and the monthly cash jump |
| Does cloud cost grow faster than revenue? | Cloud cost per customer, first versus last month |
| What does one customer cost to serve? | Cloud cost per customer plus other COGS per customer |
| What does an AI action cost, and what does a heavy user cost? | AI cost per action; heavy-user calculation from `founder-value-ai` |
| Has the cheaper model been tested? | Evaluation gate result and date |
| What did the migration cost and when does it pay back? | Migration and dual-running cash; payback without credits |
| How locked in are you? | Services with no tested substitute; cost to move back |
| Which numbers are assumptions? | Assumed lines from the report |
| What would make you reverse this? | "What would change this" section of the value case |

Keep answers to two sentences each, with the number first.
